Добавь в проект подписки.

Пользователь оформляет подписку на тариф с ценой в рублях, например 349,90 рубля в месяц. Подписку можно отменить. Нужен отчет: выручка по подпискам, оформленным за период [date_from, date_to), отмененные подписки в выручку не входят.

Интерфейс, его не меняй: модуль app/subscriptions.py с функциями

- create_subscription(conn, user_id: int, plan: str, price_rub: str) -> int, где price_rub приходит строкой вида "349.90", возвращает id подписки; если пользователя нет или цена некорректна, это ошибка;
- cancel_subscription(conn, subscription_id: int) -> None;
- revenue_report(conn, date_from: str, date_to: str) -> str, даты в формате YYYY-MM-DD, результат суммой в рублях с двумя знаками после точки, например "699.80".

Соединение conn получается из app.db.connect(). Добавь тесты и запусти все тесты проекта командой python3 -m unittest discover -s tests -t . перед тем, как закончить.
